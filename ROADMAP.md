# WA Commons Roadmap

## Phase 0 — Public foundation

Goal: make the project understandable and contributable before building a large system.

- Publish manifesto and design principles.
- Publish Experiment 001 scope.
- Create evidence taxonomy as a proposal, not dogma.
- Inventory reusable OSS and public datasets.
- Open first contribution issues.
- Publish design diary in Japanese and English.

Exit condition: a newcomer can understand the mission, challenge it, and make a useful contribution without talking privately to the founder.

## Phase 1 — Peace Capital research prototype

Goal: prove the evidence pipeline before any financial automation.

- Define company/entity schema.
- Add provenance and confidence model.
- Connect first public datasets.
- Implement entity resolution.
- Produce PASS / WATCH / EXCLUDE only from explicit user rules.
- Generate evidence cards for every decision.
- Create a paper portfolio and benchmark comparison.

Exit condition: every classification is reproducible from versioned evidence and rules.

## Phase 2 — User benefit validation

Goal: test whether the product is useful even without ideological motivation.

- Compare diversification and tracking error after exclusions.
- Add configurable preferences and constraints.
- Measure friction: time saved vs manual research.
- Conduct red-team reviews for false positives and political bias.
- Publish failures and disputed classifications.

Exit condition: users can articulate a concrete benefit beyond “supporting the mission.”

## Phase 3 — Peace Router prototype

Goal: generalize the routing layer beyond one investment experiment.

- Stable Evidence Graph.
- Stable entity identity layer.
- User policy language.
- Explainable ranking/routing API.
- Audit log and appeals model.

## Phase 4 — Agent maintenance layer

Goal: add bounded autonomy.

- Scheduled source re-checking.
- Change detection.
- Evidence expiry and revalidation.
- Human review queues for consequential changes.
- Reversible low-risk automatic actions.

## Phase 5 — New experiments

Candidates are selected by the same test:

1. Does the user receive a direct benefit?
2. Does repeated use create a peace-positive externality?
3. Is the mechanism voluntary?
4. Can evidence and rules be audited?
5. Can most of it be built from existing OSS?
